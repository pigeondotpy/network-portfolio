# Ricardo Pearce Network Engineering Portfolio

A single page responsive network engineering portfolio and CV site.

## Run locally

Open `index.html` directly in your browser.

## Deploy

You can deploy this folder as a static site on:

- Vercel
- Cloudflare Pages
- Netlify
- GitHub Pages
